# Setting up Game Center in App Store Connect

Everything on the code side is done — `Sources/Core/GameCenterService.swift` already
authenticates silently at launch and reports a lifetime-earnings score. `Sources/Fable.entitlements`
already has the `com.apple.developer.game-center` entitlement. **Nothing in this document
requires touching code.** It's the steps to make the leaderboard exist for real on Apple's
side, which only you can do (it needs your Apple Developer account and App Store Connect
access).

## 1. Enable the Game Center capability

App Store Connect → your app → **App Information** → scroll to **Game Center** → toggle it
on. (In Xcode itself this is normally a Signing & Capabilities checkbox, but since this
project is generated by `xcodegen` from `project.yml`, the entitlement is already declared
directly in `Sources/Fable.entitlements` — you only need the App Store Connect side.)

## 2. Create the leaderboard

App Store Connect → your app → **Game Center** → **Leaderboards** → **+** → **Single Leaderboard**.

| Field | Value |
|---|---|
| Leaderboard Reference Name | Lifetime Earnings |
| Leaderboard ID | `com.fable.foodcourt.leaderboard.lifetimeEarnings` |
| Score Format Type | Integer |
| Sort Order | High to Low |
| Score Submission Type | Best Score |

The Leaderboard ID **must match exactly** — it's what `GameCenterService.Leaderboard.lifetimeEarnings`
already sends scores to.

Add at least one localization (Display Name "Lifetime Earnings", Score Format "Number") —
App Store Connect won't let the leaderboard go live without one.

## 3. Test with your own Apple ID

Unlike StoreKit, Game Center doesn't need a special sandbox account — any Apple ID signed
into Game Center on a real device or the simulator works, including your own, and scores post
instantly without needing App Review approval first. Build and run the app, open **Events →
League**, and once Game Center authentication succeeds silently in the background a "Global
Leaderboard" button appears. Tap it, confirm your score shows up, and confirm the button
stays hidden if Game Center authentication fails or is declined — it's bonus flavor, never a
gate on anything else in the game.

## 4. Nothing else changes

Once the leaderboard is created, the app works exactly as it does in local testing today —
same leaderboard ID, same `GameCenterService`. There is no separate "go live" switch to flip
in code, and no App Review step specific to Game Center the way there is for IAP.

Only one leaderboard shipped this pass — lifetime earnings. A second ("fastest to open venue
5") was scoped in planning but needs a new persisted timestamp field to track when each

field on `GameState`, set once the moment venue 5 unlocks), the App Store Connect side is
